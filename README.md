# Aida Vladuta Web Project

Aplicatie web realizata folosind:

- HTML
- CSS
- JavaScript
- Node.js
- Express
- SQLite
- Open Library API

## Functionalitati

- profil personal
- lista de skills
- formular cu validare JavaScript
- cautare carti folosind Open Library API
- backend REST
- operatii CRUD pentru skills
- baza de date SQLite

## Rulare proiect

1. Instalare dependente:

npm install

2. Pornire server:

npm start

3. Aplicatia poate fi accesata la:

http://localhost:3000

## API

GET /api/skills

POST /api/skills

PUT /api/skills/:id

DELETE /api/skills/:id
